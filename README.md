# 🚀 Modern AI-Powered Blog Platform

A cutting-edge full‑stack blogging platform built using the **Monstech** stack, designed to create, manage, and explore blogs with a seamless UI. Includes **AI‑powered writing assistant** and **Imageify Cat** media support to elevate the blogging experience.

---

## ✨ Features

* 📝 Create, edit & delete blog posts
* 🤖 **AI blog writing assistant** to generate and refine content
* 🖼️ Add images using **Imageify Cat** integration
* 💬 Comment system on each blog
* 📋 User dashboard for blog management
* 🔐 Secure auth & role‑based access
* 📄 Responsive blog listing & detail pages
* 📱 Fully responsive modern UI

---

## 🛠️ Tech Stack (Monstech)

| Technology       | Usage                      |
| ---------------- | -------------------------- |
| MongoDB          | Database                   |
| Express.js       | Backend API                |
| Node.js          | Server Runtime             |
| React            | Frontend UI                |
| Tailwind CSS     | Styling                    |
| **AI Model**     | Blog writing assistant     |
| **Imageify Cat** | Image generation/embedding |

---

## 🚀 Installation & Setup

```bash
# Clone repo
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name

# Install dependencies
npm install

# Start development server
npm run dev
```

> Make sure to add environment variables for database, auth, Imageify Cat, and AI API keys.
